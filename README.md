# Trojan Horse

*a private instrument · 特洛伊木马 · 私人器具*

> **18R · Adults only.** 本工具用于生成成人向虚构角色扮演的设定文本，面向已成年、完全自愿的合意幻想。未满所在地法定成年年龄，请直接离开。

一个单文件、离线的角色扮演 prompt 生成器。
把「我想要什么」「对方是什么」「底线在哪」三件事，写成一份能直接贴给模型的说明书。

常见用法是和 AI 角色建立情感或性关系的用户；你也可以只把它当角色档案生成器，或一个反复打磨的设定草稿本。

## 使用

1. 下载 `trojan-horse.html`
2. 用浏览器直接打开（双击即可，不需要服务器，不需要安装）
3. 通过入口页的内容警告，开始填写
4. 在底部「Output」复制生成的 prompt，贴给你的模型

手机浏览器和老版本 WebView 也能用：脚本里带了兼容垫片，专门处理旧环境里「页面渲染正常、按钮却按不动」的问题。

## 它做什么

- 把偏好拆成可勾选的强度、场景与边界，不用每次重新描述
- 把对方写成「身体 + 性格 + 事后」的档案，让角色跨轮次保持一致
- 把底线写在最前面，交给模型当硬约束
- 把「同意」和「强度」分成两套机制，重口味不会被误读成许可

## 模块

| 模块 | 内容 |
| --- | --- |
| Persona · 性格 | 名字、原型、主动性、跨轮记忆、说话方式、温度／能量／语速、默认态度、惯性动作、弱点 |
| Characters · 角色 | 双方各自独立配置身体、生殖结构与人外特征，自动计算体型差 |
| Dynamic · 关系动态 | 双方定位与互相的称谓；同体系互斥，跨体系可叠加 |
| Repertoire · 玩法强度 | 「常用十项」快捷选择；可交给模型判断，或逐项挑选轻／中／重／极四档 |
| Objectification · 物化 | 独立的视角框架，只有开关和层级，没有强度档 |
| Aftercare · 事后照料 | 独立的承诺模块：程度、具体内容、时点 |
| Style · 文风规范 | 词表锁定（支持中英双语行）、禁词、声音、感官密度、审美标签、语癖、节奏与人称、输出自检 |
| Agreements · 约定与场景 | 前提约定与场景开关，默认全部关闭，开启必须填写成立条件 |
| Safety · 安全框架 | 安全词、收尾下限、硬性边界 |
| Voice · 语气风格 | 整体调性 |
| Output · 输出 | 完整版／精简版、中英文正文切换、长度统计 |

## 几条写死的规则

- **同意先于强度。** 四档量的是力度，不是同意。模型被明确禁止引入你没勾选过的玩法。
- **重档必须配事后照料。** 开了重档玩法或物化视角，却没开事后照料，生成会被拦下。
- **物化不解除安全约束。** 安全词在任何框架下都生效。
- **模型永远不代写你的行为、台词和反应。**

## 数据与隐私

- 所有填写内容只存在你自己浏览器的 `localStorage` 里，不上传、不记录
- 配置可以导出成 JSON 文件，也可以导入或复制配置，方便备份和换设备
- 「载入示例」可以先看一份完整的填写样例；「清空」会重置全部内容
- 顶部 ⚙ 是自检：检查事件通道、渲染完整性和本地存储是否正常

唯一的外部请求是 Google Fonts 字体（Cormorant Garamond、Noto Serif SC）。加载不到时会自动回退到系统衬线字体，功能不受影响。

## 它不做什么

它不生成图片，不代替你做决定，也**无法保证模型一定遵守安全框架**。
开始之前，请先和对方谈清楚，不要只依赖这份文本。

## 界面

- 日间／夜间主题切换
- 顶部「18R」可以随时重新阅读入口说明
- 键盘可操作，所有控件带焦点样式；尊重系统的「减少动态效果」设置
