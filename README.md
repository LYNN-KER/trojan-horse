## 它做什么

一个 HTML 文件，双击即开，不注册、不上传，所有填写内容只留在你自己浏览器的本地存储里。它不预设你怎么用：可以只当一份角色档案生成器，也可以当一个反复打磨的设定草稿本。

- 把偏好拆成可勾选的强度、场景与边界，而不是每次重新描述
- 把对方写成身体 + 性格 + 事后的双档案，让它跨轮次保持一致
- 把底线写死在最前面，交给模型当硬约束而不是建议
- 把「同意」与「强度」分成两套机制，不让重口味被误读成许可

## 怎么打开

下载 `trojan-horse.html`，用浏览器打开即可。

部分浏览器在 `file://` 下会限制 localStorage。页面顶部的 ⚙ 自检会显示「本地存储 不可用」，这种情况下起一个本地服务再打开：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/trojan-horse.html
```

## 几条贯穿全局的规则

- **力度不是同意。** 四档量的是强度，不是许可；两套机制分开走。
- **同意先于强度。** 前提约定与场景开关默认全关，开了就必须写成立条件。
- **重档玩法或物化视角，不开事后照料会被拦下。** 提示栏直接报错，复制按钮禁用。
- **最彻底的物化层级（猎物）必须设安全词。** 重档玩法、已开启的场景、物化视角同理。
- **文风规范永远压过语气风格。** 就算语气选了「诗性」，也只有动作层的修饰跟随调性，器官词表不会因为气氛变柔而退回委婉说法。
- **文风规范里的玩法授权是场前授予**，不解除安全框架，也永远不授权模型代写你的反应。

## 数据与隐私

- 没有账号，没有遥测，没有任何数据上传。
- 所有填写内容存在 localStorage。「导出文件」和「复制配置」给的是同一份 JSON，导入即可完整还原——重要配置请自己留一份。
- 关掉浏览器内容还在，清掉浏览器数据就没了。
- 页面里唯一的外部引用是一个 Google Fonts 样式表，断网时回落到系统衬线字体，功能不受影响。
